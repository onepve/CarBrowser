# CarBrowser - 极轻车机浏览器

专为吉利吉利车机大屏（1920×720 横屏）量身定制的极轻原生 WebView 浏览器。

## 特色功能

1. **车规常驻大顶栏**：
   - 顶部常驻 56dp 高对比大触控胶囊，包含【⬅ 后退】、【➡ 前进】、【🔄 刷新】、【🏠 主页】、【⭐ 常用收藏】、【✕ 退出】以及全功能地址/搜索栏。
   - 告别手机沉浸式无返回键、手势误触车机空调下拉条的痛点。

2. **常用网站与大磁贴收藏夹**：
   - 默认常驻显示【⭐ 常用收藏】按钮，一键弹出大卡片抽屉。
   - 预置国内热门站点：
     - **影音娱乐**：哔哩哔哩、抖音网页版、爱奇艺、腾讯视频、优酷
     - **听书阅读**：微信读书、QQ阅读、喜马拉雅、网易云音乐、QQ音乐
     - **搜索与AI**：百度搜索、必应搜索、DeepSeek、Kimi 智能助手
     - **汽车资讯**：懂车帝、汽车之家、知乎、新浪微博
   - 支持一键收藏当前网页，支持长按删除自定义收藏。

3. **下载默认直达车机 Download 目录**：
   - 下载 APK、图片或文件时，自动保存至 `/storage/emulated/0/Download/`，方便车机文件管理器查找与安装。

4. **极轻原生 WebView 架构**：
   - 不依赖庞大 Chromium 内核打包，APK 仅约 2MB，占用极低运存，完美适配 E02 座舱芯片。
